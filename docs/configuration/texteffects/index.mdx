# ✨ Text Effects

## Overview

Oraxen no longer includes TextEffects. To add animated or shader-based text effects, use a separate resource pack and merge it into the pack generated by Oraxen.

One option is [TheSalt's Text Effects](https://modrinth.com/resourcepack/thesalts-text-effects), which applies configurable effects to text based on its color.

<Callout type="info">
  Text effects are provided and configured by the external resource pack, not by Oraxen. Check the pack's documentation for supported Minecraft versions, configuration, and usage instructions.
</Callout>

## Merge a Text Effects Pack

<Steps>
#### 1. Download a compatible version of the external resource pack.
#### 2. Place the resource pack ZIP in `plugins/Oraxen/pack/uploads/`.
#### 3. Make sure Oraxen imports the pack's core shaders (`plugins/Oraxen/settings.yml`).

```yaml
Pack:
  import:
    remove_core_shaders_from_imported_packs: false
```

#### 4. Reload or restart the server to regenerate the final resource pack.
</Steps>

See [Pack Merging / Importing](/usage/merging) for the complete pack merging guide.

<Callout type="warning">
  Text effect packs commonly replace Minecraft's `rendertype_text` core shader. Oraxen's animated glyphs use the same shader, so a merged text effect pack can break them. They can also conflict with other packs that modify the same shader. Core shader files cannot be merged automatically; if multiple packs provide the same shader, you must resolve the conflict manually or choose which pack's shader to use.
</Callout>
