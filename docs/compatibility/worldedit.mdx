# 🗺️ WorldEdit

## Overview
WorldEdit and FastAsyncWorldEdit are optional dependencies. When either is installed, Oraxen uses it to paste schematics for the sapling mechanic's schematic-based tree growth.

## Usage
No configuration is needed. Install WorldEdit or FastAsyncWorldEdit and set a `schematicName` in your sapling mechanic.
