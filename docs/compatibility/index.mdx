# 🤝 Compatibility

## Overview
Oraxen integrates with many different plugins and software. The built-in integrations below are detected when the relevant plugin is installed.

## Built-in integrations

- **BlockLocker** - Furniture can use `blocklocker.can_protect` and `blocklocker.protection_type` to protect containers.
- **EcoItems** - Use `ecoitem:` / `ecoitem_id:` item references and the `ecoitem` recipe/loot forms where supported.
- **ExecutableItems** - Use the `executableitem` loot key to reference ExecutableItems.
- **WorldEdit / FAWE** - Sapling-growth schematic pasting can use WorldEdit or FAWE when installed.

Oraxen also integrates with the detailed plugins documented in this section. If you want to let users know that your plugin or another plugin / software is compatible, consider adding your page through <Highlight color="#1877F2" to="https://github.com/oraxen/docs.oraxen.com">**GitHub**</Highlight>.
