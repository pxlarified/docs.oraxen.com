# 🧪 MMOItems

## Overview
Oraxen includes built-in MMOItems compatibility. This allows you to import items created with MMOItems and use them as a base for your Oraxen items (you will keep everything configured with MMOItems and add your own mechanics, textures, 3d models, etc).

## Usage
```yaml
mymmoitem:
  displayname: "<gradient:#59A7EA:#F1D2FF>Test"
  mmoitem:
    type: SWORD
    id: FALCON_BLADE
    level: 10 # Parsed but currently not applied
    tier: RARE # Parsed but currently not applied
```

<Callout type="warning">
  `level` and `tier` are currently non-functional in the imported item build. The removed `match_level` key is not parsed.
</Callout>
