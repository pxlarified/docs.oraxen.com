# 🧱 Bedrock

## Overview
Oraxen itself doesn't have direct Bedrock / Geyser compatibility.
However, there are extensions that make it possible to use Oraxen resourcepacks on Bedrock.

We recommend using <Highlight color="#1877F2" to="./feather">**FeatherConvert**</Highlight>.
