# 📘 Introduction

## Overview
Oraxen allows you to customize your Minecraft server by allowing the creation of new blocks, items, and recipes. 
This can be accomplished entirely through a resource pack and server-side implementation, eliminating the requirement for any client-side mod installations.

## How It Works
Oraxen reads your configuration files and uses them to generate a Minecraft resource pack that will then be uploaded to a resource pack server which then sends the pack to players joining your server.
Polymath is a free and open-source software written in Python by Oraxen to host Minecraft resource packs. Oraxen supplies you with a free Polymath instance, hosted in Switzerland on an Oracle Virtual Private Server.

## Version
Oraxen is developed for <Highlight color="#1877F2" to="https://papermc.io/downloads/paper">**Paper**</Highlight>, Paper forks, and <Highlight color="#1877F2" to="https://papermc.io/software/folia/">**Folia**</Highlight>. Spigot and CraftBukkit are not supported and the plugin will not load there.
Oraxen includes support for versions from **1.20.1** up to **26.2**. Oraxen has ViaVersion support, for that please read the documentation <Highlight color="#2E8B57" to="./compatibility/viaversion">**here**</Highlight>.

## Installation
Drag and drop the `.jar` file into your server's `/plugins` folder and restart your server.

<Callout type="note">
  PacketEvents or ProtocolLib is recommended for the fullest feature set. Without either, Oraxen still enables with a limited adapter and some features degrade. Since version 1.203.1, Oraxen automatically downloads PacketEvents when not already installed (subject to the configured download policy).
</Callout>
